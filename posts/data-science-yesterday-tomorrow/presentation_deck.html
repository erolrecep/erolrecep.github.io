Act II: Across the Stack

Layer 3: Physical Edge Systems — Computer Vision on UAVs

Unmanned Aerial Vehicles (Drones)

  • Real-time image processing on low-power embedded processors
  • Unforgiving memory constraints and strict battery milli-watt budgets

The Lesson

You cannot hide behind an infinite cloud cluster. Algorithmic complexity (O(N) vs O(N²)) and sensor vibration noise demand real engineering rigor.

Explain how physical systems enforce computational discipline. When compute and power are finite, algorithmic efficiency is non-negotiable.

After

Restructured memory layouts, vectorization, and parallel decomposition: under 2 hours.

"Brute-force cloud compute is expensive and lazy. Algorithmic optimization is an enduring scientific superpower."

Act III: The Scale Frontier

Heterogeneous Computing: Balancing CPUs & GPUs

  • Modern AI is fundamentally heterogeneous:
    • Host CPUs: Complex branching, serial logic, pipeline orchestration.
    • Device GPUs/Accelerators: Massive parallel tensor contractions.
  • The Real Ceiling: PCIe bus transfer latency and memory hierarchy.

Hardware Fluency

You cannot effectively scale modern foundation models if you treat the underlying silicon as a magic black box.

Demystify GPUs. Understanding memory transfers between CPU host and GPU device is essential for training and serving large models.
Act III: The Scale Frontier

Green Computing: The Energy-Efficient Computing Mandate

Training frontier models consumes gigawatt-hours of electrical energy.

The New Metric

FLOPs / Watt

Maximizing model intelligence per unit of energy consumed.

  • Quantization (INT8, FP4) and sparse architectures
  • Pruning, distillation, and efficient attention mechanisms
  • Sustainable AI is one of the highest-impact fields of the next decade
Introduce energy efficiency and green computing as an imperative. Accuracy at any cost is no longer acceptable in the real world.

The Clinical Reality: The 99.7% Model That Kills

The Task: Predict cancer patient remission from 50,000 hospital records.

The AI Agent Result: Generates code in 45s, achieves a staggering 99.7% ROC-AUC.

Top Predictive Feature: DISCH_CODE_902

Hospital Clerk: "Oh, that's the billing code we enter into the accounting system when a patient is formally discharged in full remission!"

Target Leakage. The model didn't cure cancer—it memorized an administrative timestamp.

Walk through the horror of deploying this model. Non-technical managers would celebrate the 99.7% AUC. Only a data scientist with domain skepticism catches the fatal flaw.

Act IV: The Driver's Seat

The Reactive Revolution: Marimo.io

Legacy Jupyter Notebooks

Out-of-order execution, hidden global states, unreproducible scratchpads. AI hallucinates on stale memory.

Marimo Reactive DAG

Deterministic, pure Python files, Git-friendly, upstream changes automatically propagate downstream. AI is natively contextual.

"Marimo represents the modern archetype: deterministic, reproducible, and built for AI-assisted empirical science."
Introduce Marimo as the modern standard. Explain why reproducible computational DAGs prevent the chaos of out-of-order notebook cells.
