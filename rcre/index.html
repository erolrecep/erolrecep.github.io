Core Principles

Architected for Speed & Reliability

Zero Dynamic Allocations

All algorithms operate strictly inside 64-byte aligned linear scratchpad memory arenas (`RCRE_Arena`). Inference loops never invoke `malloc`, guaranteeing deterministic real-time latency.

Integration

Drop-In Single-Header C23

// 1. Include RCRE single-header implementation
#define RCRE_IMPLEMENTATION
#include "rcre.h"

int main(void) {
    // 2. Initialize 64-byte aligned linear memory arena (no malloc in loops!)
    RCRE_Arena* arena = rcre_arena_create(32 * 1024 * 1024);

    // 3. Create strided 3D image tensor [480, 640, 3] U8
    size_t shape[3] = {480, 640, 3};
    RCRE_Tensor img = rcre_tensor_create(shape, 3, RCRE_DTYPE_U8, RCRE_LAYOUT_HWC, arena);

    // 4. Execute SIMD-accelerated Rec.601 Grayscale & Gaussian Blur
    size_t gray_shape[2] = {480, 640};
    RCRE_Tensor gray = rcre_tensor_create(gray_shape, 2, RCRE_DTYPE_U8, RCRE_LAYOUT_HWC, arena);
    rcre_cv_rgb_to_gray(&img, &gray);

    rcre_arena_destroy(arena);
    return 0;
}
