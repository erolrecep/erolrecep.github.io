  • RCRE — Recep’s Code Run Everywhere (v0.2.5 — in-development)
    A single-header, zero-dependency C23 engine unifying modern Computer Vision, Reverse-Mode Autograd, Classical Machine Learning, and Generative Transformers across Edge, HPC, and WebAssembly with zero heap allocations in inner inference loops. Features 15-bit fixed-point color kernels with 0 LSB discrepancy vs. OpenCV, subpixel continuous resizing, Harris corners, DLT/RANSAC homography, Lucas-Kanade optical flow, scalar DAG & tensor tape autograd, decoder-only generative transformers with O(1) KV-caching, tabular GBDT inference (7.86M preds/sec), and embedded HNSW vector search (44k QPS).

  • GNew Parallel (gnewp) (v0.2.2 — in-development)
    A topology-, SIMD-I/O-, and accelerator-aware modernization of GNU Parallel written in ISO C23 and powered by RCRE v1.1. Preserves the core zero-daemon Unix CLI ergonomics (:::, ::::, --pipe, {}, {.}, {/}, --colsep, --joblog, --resume-failed, -k) while replacing the 15,000-line Perl interpreter core with a zero-dependency systems engine. Features shell-bypass direct execution (posix_spawnp) with arena scratchpads, ARM NEON & x86 AVX2 SIMD --pipe stream splitters (2.12–3.24 GiB/s for FASTQ/FASTA/TSV), Apple Silicon P/E-core steering via Mach QoS, Linux cgroups v2 and Slurm CPU quota sympathy, live memory pressure guards, dynamic runtime NVML GPU VRAM-gated scheduling, and loss-proof --worker process pools (delivering 2.0x–23.6x faster orchestration and 11.5x lower RAM).

  • Best Practices for Using HPC: Scaling Up to Cluster-Native Workflows (November 2026)
    Comprehensive workshop curriculum, interactive slide deck, and practical guides presented at the Rice University Center for Research Computing (CRC) Research Computing Day. Designed to bridge the gap between running code on personal laptops and scaling compute jobs across large-scale supercomputing clusters. Covers login node etiquette, memory over-allocation traps, multi-core CPU and GPU resource sizing, high-speed shared file systems (Lustre/NFS), Slurm batch script templates, job monitoring with seff, and reproducible cluster-native workflows.

  • Profiling Hardware Accelerated Computations for CPU & GPU (November 2026)
    A practical, diagnostic guide and hands-on workshop focused on making computational science and AI workloads run 10x to 1,000x faster across modern hardware architectures (NVIDIA GPUs, Apple Silicon MPS, and multi-core x86/ARM CPUs). Teaches a simple 3-step triage workflow (Run → Spot → Fix) using system-wide macro timeline profiling (nsys), kernel micro-architecture inspection (ncu), deep learning operator tracing (torch.profiler), line-by-line profiling (Scalene), and heap allocation flamegraphs (Memray). Demonstrates how cache-friendly loop reordering, eliminating Python scalar synchronizations (aten::_local_scalar_dense), and 1D grid-stride loops eliminate warp divergence and unlock peak silicon throughput.

    • 📓 Google Colab Interactive Cloud Lab
    • 💻 GitHub Repository
